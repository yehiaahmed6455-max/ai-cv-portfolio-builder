# ProCV - AI-Powered CV & Portfolio Generator

**اعمل سيرتك الذاتية الاحترافية في دقائق - Build Your Professional CV in Minutes**

## 🚀 نظرة عامة | Overview

منصة ذكية وسهلة الاستخدام لتوليد سيرة ذاتية واحترافية وبورتفوليو جذاب باستخدام تقنيات متقدمة.

An intelligent and user-friendly platform for generating professional CVs and attractive portfolios using advanced technology.

## ✨ المميزات | Features

- 🎨 **تصميم احترافي** - Professional, modern templates
- ⚡ **توليد ذكي** - AI-powered content generation
- 📥 **تحميل متعدد** - Download in PDF, Word, or HTML format
- 📱 **متجاوب** - Fully responsive design
- ✏️ **قابل للتعديل** - Easy to customize
- 🔒 **آمن وخصوصي** - Secure and private
- 🌐 **متعدد اللغات** - Arabic & English support

## 🛠️ التقنيات المستخدمة | Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Design**: Responsive Grid Layout
- **Icons**: Font Awesome 6.4
- **Deployment**: Replit / GitHub Pages / Custom Domain

## 🚀 البدء السريع | Quick Start

### محلياً | Locally

```bash
# Clone the repository
git clone https://github.com/yehiaahmed6455-max/ai-cv-portfolio-builder.git

# Navigate to project
cd ai-cv-portfolio-builder

# Open in browser
open index.html
```

### على Replit

1. Fork المشروع على Replit
2. اضغط "Run"
3. انسخ الرابط الناتج

## 📖 كيفية الاستخدام | How to Use

1. **زر البداية** - اضغط "ابدأ الآن" في الصفحة الرئيسية
2. **ملء البيانات** - أدخل معلوماتك الشخصية والمهنية
3. **توليد السيرة** - اضغط "توليد السيرة الذاتية"
4. **التحميل** - حمل الملف بصيغة PDF أو Word
